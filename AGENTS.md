Every change from here is a **repair**, never an **addition**.

  build/CI, security holes, dependency rot that stops it building.
- **Never again:** new screens, new systems, new settings, new data fields,
  "small quality-of-life" tweaks, speculative refactors.
- **There is no backlog.** Any plan file in this repo is a historical record, not a
  to-do list. Do not add to it, do not write a new one, do not work items off it.
- A change that cannot be stated as *"this was broken, now it works"* does not go in.
- If a request would add a feature, say so plainly and stop. The answer is no.

## Multi-Agent Workflow

- Everyone commits to `main`. One fix, one push. No feature branches.
- **NEVER hand-edit** `src/version.ts` or this file — centrally managed.
- Every push runs CI (typecheck / lint / test / build). A red check stops all work
  until it is green again.
- Production broken after deploy? Instant-Rollback on Vercel first, then find the
  cause. Never force-push.

## Update Flow (per fix)

- Bump `APP_VERSION`, update `LAST_UPDATE_DATE` / `LAST_UPDATE_TIME`, and prepend
  one entry to `RELEASE_HISTORY` in `src/version.ts`.
- `public/version.json` is generated by `pnpm build`. Never hand-edit it.
- `pnpm test` runs through `tsx --test`: plain `node --test` cannot resolve the
  `.js` relative imports inside `api/_shared/`.

## Hard UI Rules (each one was a real bug — do not violate)

- Full-screen modals: ALWAYS render via `createPortal(..., document.body)`. Fixed elements inside transformed ancestors break positioning.
- Red-dot badges: bottom-right (`-bottom-0.5 -right-0.5`), never top-right.
- Critical actions (delete etc.): never hover-only — must be visible/tappable on touch devices.
- Italic text: add `pr-1` (or similar) to prevent right-edge clipping.
- Colors: theme-aware (`indigo-400/500`, slate+opacity). Avoid `bg-emerald-500`-style hardcodes, `indigo-200`, and `indigo-700+` for primary elements. Dark themes: night/forest/ocean. Light: daylight/warm/candy.

## Web Push Troubleshooting (in order)

1. Test in a new tab or installed PWA (iframes block push) -> 2. permission "Allowed" -> 3. SW console `Application > Service Workers > Inspect` -> 4. OS focus-assist -> 5. Dev settings "Test Local Notification (Direct)" -> 6. VAPID keys changed? Then "Clear Server Sub" + "Reset Service Worker".
