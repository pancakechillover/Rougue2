## 已知不是 bug 的现象（别误报）

| 现象 | 原因 |
|---|---|
| Console 报 `Failed to register a ServiceWorker` | Preview 环境没配 sw.js 的 MIME 类型，线上正常 |
| Console 报 `Vercel Web Analytics` 加载失败 | 本地/预览没部署 Analytics，线上正常 |
| 24h 环形时钟一片空白 | 当天没有工位记录，打卡后才有内容 |
| 刷新后回到首页 | 若发生在直连 `/xxx` 路径时，是 Preview 环境的 SPA fallback 限制；线上 Vercel 正常 |
